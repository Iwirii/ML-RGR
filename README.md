## Описание проекта

Web-приложение (дашборд) разработано с использованием библиотеки Streamlit. Основная цель — предоставить удобный интерфейс для анализа данных и получения предсказаний стоимости жилой недвижимости с помощью шести обученных моделей машинного обучения.

Приложение включает 4 страницы:
- **О разработчике** — информация об авторе проекта
- **Датасет** — описание данных и результаты разведочного анализа (EDA)
- **Визуализации** — 5 интерактивных графиков зависимостей
- **Инференс** — выбор модели и получение предсказания (ручной ввод или загрузка CSV)

---

## Датасет

- **Источник:** King County House Sales (2014–2015)
- **Записей:** 21 613
- **Целевая переменная:** price (USD)

## Функциональность дашборда

### Страница 1 — О разработчике
- Фотография, ФИО, группа, университет
- Тема РГР
- Стек технологий

### Страница 2 — Датасет
- Описание предметной области и признаков
- Результаты EDA (анализ распределений, корреляций, выбросов)
- Информация о предобработке и инженерии признаков
- Просмотр первых строк и статистики данных

### Страница 3 — Визуализации (5 интерактивных графиков)
1. Гистограмма распределения цен (с регулировкой числа столбцов и log-шкалой)
2. Тепловая карта корреляций Пирсона
3. Диаграмма рассеяния (выбор признака vs цена)
4. Ящик с усами (распределение цен по числу спален)
5. Линейный график (динамика цен по году постройки)

### Страница 4 — Инференс
- Выбор модели из 6 доступных
- **Ручной ввод:** заполнение характеристик через виджеты (слайдеры, числовые поля, выбор района)
- **Загрузка CSV:** пакетная обработка нескольких объектов
- Автоматическая инженерия признаков перед предсказанием
- Вывод результата в формате `$XXX,XXX USD`
- При загрузке CSV с колонкой `price` — расчёт ошибок (абсолютной и процентной) и возможность скачать результат
